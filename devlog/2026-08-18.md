## 关键决策

1. **公开仓库 + key 走代理**（用户选定）：代码可以公开，但 Google/OpenAI 的 key 只存在 Vercel 环境变量里，前端只调用自家 `/api/*` 接口
2. **开发/生产路径统一**：开发环境 vite 代理转发 `/api/geocode`、`/api/distance`、`/api/chat` 并注入 key（从 .env.local 读），生产环境由 Vercel serverless 函数处理——前端代码对两个环境无感知
3. **base 路径改 '/'**：Vercel 部署在根路径；如需换回 GitHub Pages，vite.config.ts 改回 `/nyc-rental-finder/`
4. **chat 接口钳制参数**：公开接口任何人都能调，temperature ≤1、max_tokens ≤1000，防止被恶意调用烧钱

## 遇到的问题

1. **`.env` 里有 OpenAI key 且未被 gitignore**：最初 `.gitignore` 只忽略 `*.local`，`.env` 会被提交到公开仓库——已迁移到 `.env.local` 并删除 `.env`，同时 `.gitignore` 补上 `.env`/`.env.*`
2. **build-apartments.mjs 硬编码 Google key**：脚本第 27 行有 key 字面量，公开仓库会泄露——改为读环境变量/`.env.local`，缺失时明确报错退出
