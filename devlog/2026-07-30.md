## 关键决策

1. **状态管理选 Zustand 而非 Context**: 避免地图不必要重渲染，persist 中间件一行代码搞定 localStorage
2. **地图用原生 Mapbox GL JS 而非 react-map-gl**: 更灵活的多边形交互控制
3. **MVP 先不做地图全量探索**: 地图只标注筛选后的匹配片区
4. **部署选 GitHub Pages**: 免费、配置简单、适合静态 SPA
